# API and Architecture Notes

This document logs real-world behavior, verified payloads, API nuances, and design decisions.

## 1. Verified Live Endpoints & Formats

### 1.1 Polymarket Gamma API (Market Discovery & Resolution)
- **Endpoint**: `https://gamma-api.polymarket.com/events?slug={slug}`
- **Slug Format**: `btc-updown-5m-{window_start_epoch}` where `window_start = (unix_ts // 300) * 300`.
- **Market Question & Description**:
  - Example Question: `"Bitcoin Up or Down - October 26, 1:50PM-1:55PM ET"`
  - Description:
    > "This market will resolve to 'Up' if the time-weighted average price (TWAP) of Bitcoin, generated by Chainlink, of the time range specified in the title is greater than or equal to the price at the beginning of that range. Otherwise, it will resolve to 'Down'."
  - **Tie Rule**: If `end_twap == start_price`, the market resolves **Up** (`>=` rule).
- **Resolution**:
  - Polled via `outcomePrices`: `["1", "0"]` (Up wins) or `["0", "1"]` (Down wins).
- **Network Resilience**:
  - Certain Windows environments / CloudFront nodes may trigger `ConnectionResetError (10054)` on rapid TCP handshakes.
  - Implement robust retries with backoff and persistent sessions.

### 1.2 Polymarket RTDS WebSocket (Chainlink Price Feed)
- **Endpoint**: `wss://ws-live-data.polymarket.com`
- **Subscription Payload**:
  The prompt noted `action: subscribe, topic: crypto_prices_chainlink, filter: btc/usd`.
  Verified schema requires an array of subscriptions:
  ```json
  {
    "action": "subscribe",
    "subscriptions": [
      {
        "topic": "crypto_prices_chainlink",
        "type": "update"
      }
    ]
  }
  ```
- **Keepalive**:
  Must send `"PING"` text frames every 5 seconds; server responds with `"PONG"` or empty frame.
- **Message Structure**:
  ```json
  {
    "topic": "crypto_prices_chainlink",
    "type": "update",
    "timestamp": 1793037789919,
    "payload": {
      "symbol": "btc/usd",
      "timestamp": 1793037788000,
      "value": 80266.84176528388,
      "full_accuracy_value": "80266841765283890000000"
    }
  }
  ```
  Note: Filter client-side for `payload.symbol.lower() == "btc/usd"`.

### 1.3 Binance WebSocket (Cross-check Feed)
- **Endpoint**: `wss://stream.binance.com:9443/ws/btcusdt@trade`
- **Message Structure**:
  ```json
  {
    "e": "trade",
    "E": 1793037547086,
    "s": "BTCUSDT",
    "p": "80358.10000000",
    "q": "0.002",
    "T": 1793037547474
  }
  ```
  Price is in `"p"`, event time in `"T"`.

### 1.4 Polymarket CLOB WebSocket (Order Book & Trades)
- **Endpoint**: `wss://ws-subscriptions-clob.polymarket.com/ws/market`
- **Subscription Payload**:
  ```json
  {
    "assets_ids": [token_up, token_down],
    "type": "market"
  }
  ```
- **Initial Snapshot Message**:
  List of book objects:
  ```json
  [
    {
      "market": "0x...",
      "asset_id": "...",
      "timestamp": "1793037645135",
      "hash": "...",
      "bids": [{"price": "0.45", "size": "100.0"}, ...],
      "asks": [{"price": "0.55", "size": "150.0"}, ...]
    }
  ]
  ```
- **Delta Update Messages**:
  ```json
  {
    "market": "0x...",
    "price_changes": [
      {
        "asset_id": "...",
        "price": "0.99",
        "size": "45195.3",
        "side": "BUY",
        "hash": "..."
      }
    ]
  }
  ```
- **Local Order Book Maintenance**:
  - Size == 0 means remove price level.
  - Size > 0 updates or inserts price level.
  - Bids sorted descending, asks sorted ascending.

## 2. Data Storage Formats (Recorder)

### Directory: `data/raw/{window_start}/`
Each window directory contains:
- `chainlink.jsonl`: `{"received_at_ms": ..., "feed": "chainlink", "price": ..., "raw": ...}`
- `binance.jsonl`: `{"received_at_ms": ..., "feed": "binance", "price": ..., "raw": ...}`
- `market.jsonl`: `{"received_at_ms": ..., "event_type": "snapshot"|"delta", "token_id": ..., "side_token": "Up"|"Down", "raw": ...}`
- `metadata.json`: window start, end, slug, tokens, K (start price), creation time.
- `resolution.json`: outcome prices, winner ("Up" or "Down"), settled timestamp.

Past windows are compressed into `data/raw/{window_start}.tar.gz` and cataloged in `data/raw/manifest.json`.
兼容 `polyticker`'s convention of per-interval `chainlink.jsonl`, `binance.jsonl`, `market.jsonl`.
